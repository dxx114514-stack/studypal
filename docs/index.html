学习闭环

一个应用，覆盖学和练

从看懂一道题，到把它变成三个月后还不会忘的复习卡片。

◎

拍照答疑

两种模式：苏格拉底式思路提示，或解题专家给完整解析。支持图片直接提问。

✎

写作批改

中文与英文作文，百分制总分 + 分类问题 + 逐句修改建议 + 全文润色范文。

⌘

笔记转导图

粘贴笔记自动梳理成层级结构，纯 SVG 画布可缩放拖拽，兼容 OneLook 导入。

↻

间隔复习

1 / 3 / 7 / 14 / 30 天间隔，四档评分（忘了 / 困难 / 一般 / 简单）自动排期。

✧

错题本

答疑结果一键沉淀成错题，与 AI 生成的题目卡统一管理，随时重刷。

◍

AI 对话

多轮会话保留历史，可切换、删除。最近错题会作为上下文注入，讲解更贴你。

▤

学习计划

按天安排任务，勾选完成，到点本地提醒，首页直接看今天还剩多少。

⇄

自由换模型

OpenAI 兼容、Anthropic、Gemini 三协议通吃，也支持 Ollama 等本机模型。

隐私与成本

没有中转服务器

请求从你的设备直接发给你选择的模型服务商。项目方不参与转发，也看不到你的 Key 和题目。

  • ✓不自带 API Key：Key 由你自己填写，费用直接结算给服务商，我们不经手。
  • ✓数据本地优先：笔记、卡片、对话都存在本机 IndexedDB。
  • ✓密钥加密：桌面端用系统安全存储（DPAPI / Keychain）加密保存。
  • ✓无需登录：没有账号体系，卸载即带走全部数据。
  • ✓全流式输出：边生成边阅读，不用盯着空白页等一长段。
